# Design System Direction

## Product personality
Music × culture × internet × recognition.

Avoid making the interface feel primarily like a crypto exchange. Social Capital should feel like recognition and status, not financial speculation.

## Visual direction
Explore:
- expressive typography
- strong album/artist imagery
- audio waveforms
- bold numbers for recognition
- playful motion
- celebratory moments
- clear hierarchy
- dark or high-contrast foundations if they support music/media content

The exact palette, typefaces, radii, spacing and iconography are design decisions to be explored, not requirements from the PRD.

## Core components
- App shell
- Bottom navigation
- Artist card
- Song card
- Audio player
- Shoutout CTA
- Tier card
- Identity result
- Identity badge/disambiguator
- Social Capital score
- Leaderboard row
- Status chip
- Timeline/waveform
- Voice recorder
- Payment summary
- Order status tracker
- Notification item
- Empty state
- Error state
- Moderation state

## Motion opportunities
- Shoutout purchase confirmation
- Name mention reveal
- Social Capital increase
- Leaderboard movement
- Audio waveform interactions
- Recording feedback
- Published moment reveal

Motion should reinforce recognition, not become decorative noise.

## Accessibility baseline
Use WCAG-aware contrast, touch target sizing, readable typography, clear focus/selection states, semantic labels, and reduced-motion alternatives where appropriate.
