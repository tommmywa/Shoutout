# User Roles

## Fan
Primary jobs:
- Discover artists/songs
- Purchase a shoutout
- Select a specific Name Identity
- Customize according to tier
- Pay
- Track fulfillment
- Listen/watch the resulting recognition moment
- View Social Capital and leaderboard

## Artist
Primary jobs:
- Manage profile
- Manage songs
- Create shoutout opportunities
- Review incoming orders
- Review Platinum voice notes
- Record shoutouts
- Publish updated tracks
- View earnings
- Later: go live and fulfill real-time shoutouts

## Admin
Primary jobs:
- Moderate content
- Review identity claims
- Review identity merge requests
- Review fraud flags
- Monitor transactions/payouts
- Oversee compliance and consent

## Permission principle
Do not expose artist/admin functionality inside the fan experience. Role should determine navigation and access.
