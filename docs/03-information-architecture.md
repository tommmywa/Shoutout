# Mobile Information Architecture

## Fan navigation — Phase 1

### Home
- Featured artists
- Featured songs
- Trending/recent shoutout moments
- Recognition highlights
- Entry points to Explore

### Explore
- Artists
- Songs
- People
- Search
- Categories/filters where useful

### Activity
- Active shoutouts
- Completed shoutouts
- Payment history
- Notifications

### Profile
- Account
- Recognition
- Purchased shoutouts
- Settings
- Help

### Global entry points
- Search
- Notifications
- Shoutout CTA

## Artist navigation — Phase 1
- Dashboard
- Songs
- Shoutouts
- Earnings
- Profile

## Future Phase 2 navigation
Live should be introduced as a new destination or prominent Home module without restructuring existing core objects.

Potential Phase 2:
Home | Explore | Live | Activity | Profile

Do not force a Live tab into Phase 1 if it has no content.

## Core hierarchy

Consumer mental model:

Home/Explore → Artist → Song → Person → Shoutout → Recognition

Underlying system model:

Song → Shoutout → Name Identity → Social Capital Event

The underlying identity model must not leak into the primary consumer navigation.
